# Amadan World

A landscape, 3D-projected battlefield shooter for Android built with Flutter and Flame.

## Features

- Cinematic splash screen and an animated lobby with a fully articulated soldier, weapon loadout and high score.
- Four weapons with distinct fire rate, damage, magazine, reload time, recoil, spread, range, zoom and sound:
  AR-7 assault rifle, VX-9 SMG, K-12 shotgun and LR-50 sniper rifle (penetrating rounds).
- Perspective "mode-7" ground, textured 3D buildings, sandbag walls, barriers and crates with side shading,
  ambient occlusion and distance fog, plus billboard wrecks, trees, rocks, hedgehogs, barrels and debris.
- Skeletal soldiers posed in 3D (idle, walk, run, sprint, aim, shoot, recoil, reload, hit, death) and rendered
  from any facing angle.
- Endless, progressively harder waves with four enemy types (rifleman, rusher, heavy gunner, marksman) and a
  boss every fourth wave (minigun bursts, grenade barrages with ground telegraphs, charge attack, escorts,
  critical-health danger pulse with heartbeat audio).
- Headshots, damage falloff, hit markers, score popups, medkit drops, off-screen threat indicators.
- HUD: health and stamina (top left), score and wave, live mini-map with zones, enemies, boss and pickups
  (top right), separate pause button, ammo panel and boss health bar.
- Pooled bullets, enemies, particles, grenades, pickups and decals: memory stays flat in endless play.
- Two-batch `drawRawAtlas` particle rendering, batched `drawVertices` terrain and cached text layouts.

## Controls

| Control | Action |
| --- | --- |
| Left side drag | Floating joystick: move and turn |
| Fire (large red) | Hold to shoot. Auto-targets the nearest visible enemy in front of you |
| Aim (blue) | Toggle aim lock: zoom, tighter spread, slower movement, locks onto a target |
| Reload (amber) | Reload the magazine |
| Sprint (green) | Hold while moving to sprint (uses stamina) |
| Pause (top right, beside the mini-map) | Pause menu |

## Running

```
flutter pub get
flutter run --release
```

Platform folders other than `android/` are not included. To add them (or to refresh Android
templates for a much newer Flutter release), run `flutter create . --platforms=android,ios` in this folder;
existing files are kept.

## Project layout

```
lib/
  main.dart, app.dart        entry point, orientation, theme
  audio/                     audio manager (pools, music, ambient loop)
  components/                Flame components: world renderer, HUD, screen effects, mini-map builder
  entities/                  player, enemies, projectiles, soldier rig
  game/                      AmadanGame, session, input, HUD layout
  screens/                   splash, lobby, game screen
  systems/                   projection, battle map, bullets, effects, enemy director, player controller
  ui/                        controls, pause and game-over overlays, widgets, lobby soldier, atmosphere
  utils/                     asset paths, image cache, persistence, math
  weapons/                   weapon specs and runtime state
assets/
  audio/ backgrounds/ characters/ effects/ enemies/ images/ maps/ sprites/ ui/ weapons/
tool/
  gen_images.py, gen_audio.py   procedural generators for every bundled asset
```

All bitmaps and sounds are original and generated by the scripts in `tool/`
(`python3 tool/gen_images.py` and `python3 tool/gen_audio.py`, requiring numpy and Pillow).
